# CS300
Data Structures and Algorithms


## 1. What was the problem you were solving in the projects for this course?
The goal of these projects was to develop a program that could store, organize, and display course information for a Computer Science program. I learned about different data structures and wrote pseudocode for each one to compare their runtime and memory usage. Based on this analysis, I developed a program that sorts and displays a list of courses in alphanumeric order.

## 2. How did you approach the problem? Consider why data structures are important to understand.
I approached the problem by comparing the advantages and disadvantages of different data structures. I think choosing the right data structure is important because each data structure stores, searches, and processes data differently. I learned that the choice of data structure can affect the speed and memory usage of a program.

## 3. How did you overcome any roadblocks you encountered while going through the activities or project?
I had more difficulty writing the function to delete nodes than other functions. I had to handle the deletion differently depending on the position of the node. When recursion was involved, it became even more complicated and confusing. However, I worked through each condition step by step and kept fixing parts of the code that did not work correctly. After repeating this process, I was finally able to solve the problem.

## 4. How has your work on this project expanded your approach to designing software and developing programs?
Through these projects, I learned that it is important to plan the structure of a program before writing code. In the past, I mainly focused on making sure that my program worked correctly. Now, I understand that I also need to consider runtime efficiency and memory usage. I have also learned to think about the requirements of a program and the type of data before choosing a data structure.

## 5. How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?
I learned that dividing a program into smaller functions and using clear variable names can make code easier to read and maintain. When each function has a clear purpose, it becomes easier to modify the code or find errors later. I also learned that choosing the right data structure is important when adding new features or changing existing features in a program.
